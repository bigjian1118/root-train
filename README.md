# 芯心向荣 AIC —— 校园 AI 心理健康测评系统

## 一、项目简介

芯心向荣 AIC 是一款面向校园学生与教师的心理健康辅助平台，结合 SCL-90 心理测评、视频面部状态分析、人工智能对话和教师端管理功能，为学生提供心理健康自评与科普支持，辅助教师开展学生心理健康管理。

系统提供学生端与教师端，支持心理测评、历史报告查询、心理科普、咨询预约等功能。

**说明：** 本系统仅用于心理健康教育与辅助分析，不替代专业心理诊断。

## 二、主要功能

### 学生端

- 学生注册、登录与账号管理
- SCL-90 心理健康测评
- 历史测评结果查询
- 视频面部状态分析
- AI 心理陪伴与报告解读
- 心理健康科普与咨询预约

### 教师端

- 教师注册、登录与账号管理
- 学生测评记录管理
- 班级测评情况查看
- 心理健康风险辅助提示
- 咨询预约及相关业务管理

## 三、技术架构

| 模块 | 主要技术 |
|---|---|
| 前端 | Next.js、React、TypeScript |
| 后端 | Python、Flask、SQLAlchemy |
| 数据库 | PostgreSQL、pgvector |
| 文本测评 | SCL-90、随机森林辅助分析 |
| 视频分析 | py-feat |
| AI 对话 | 支持 Qwen 模型及兼容接口的远程模型服务 |
| 知识检索 | BGE-M3、RAG |
| 部署 | Linux 服务器部署、Windows 便携版 |

不同部署方式的 AI 服务配置可能不同。

## 五、安装与运行

### 1. 源代码部署

项目详细架构、依赖配置及部署说明请查看：

[ai-psy/README.md](ai-psy/README.md)

运行前需根据实际部署环境准备 PostgreSQL、Python、Node.js 及相关依赖。

### 2. Windows 便携版

项目另提供 Windows 便携运行方案，包含启动、停止和数据库初始化脚本。

具体使用方法请查看：

[Windows 便携版使用说明](portable-windows/run/使用说明.txt)

便携版在完整运行包中使用 `启动.bat` 启动，默认本地访问地址：

`http://localhost:6006`

**注意：** GitHub 仓库中的便携版脚本不包含完整运行环境、模型权重及数据库文件。仅下载脚本无法直接运行完整系统。

### 3. 环境配置

项目提供 `.env.example` 配置模板。

使用前需按照实际部署环境配置数据库连接、模型服务及应用密钥。

不得将真实 API Key、数据库密码或包含用户数据的文件提交到公开仓库。
