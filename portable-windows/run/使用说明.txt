============================================================
 心晴·校园心理健康测评系统 — 便携版使用说明
============================================================

本文件夹是完全自包含的便携版：内置 Python / Node.js / PostgreSQL
运行环境与全部模型权重，不需要在电脑上安装任何东西，可直接在
移动硬盘上运行，也可以整体拷贝到任意 64 位 Windows 10/11 电脑。

------------------------------------------------------------
一、目录结构
------------------------------------------------------------
  runtime\   运行环境（python / venv / node / postgres）
  models\    本地模型（bge-m3 向量模型 / pyfeat 表情分析权重）
  app\       系统源码、前端构建产物、配置文件 .env、上传目录、日志
  data\      数据库数据（所有账号、测评记录、报告都在这里）
  run\       本脚本目录（初始化 / 启动 / 停止）

------------------------------------------------------------
二、首次使用（只做一次）
------------------------------------------------------------
  1. 用记事本打开 app\.env，把 REMOTE_API_KEY= 后面填上你的
     DeepSeek 密钥（在 platform.deepseek.com 充值获取）。
     不填密钥也能跑，但 AI 聊天/报告解读会报错，其余功能正常。
  2. 双击 run\初始化数据库.bat，等待出现 [OK] Database initialized。
     以后换电脑、换硬盘都【不需要】重新初始化——数据就存在
     data\pgdata 里，跟着文件夹走。

------------------------------------------------------------
三、日常使用
------------------------------------------------------------
  启动：双击 run\启动.bat
        等待出现 [OK] All services started（首次启动向量模型
        加载约需 1-5 分钟，属正常）。
  访问：浏览器打开  http://localhost:6006
        局域网其他电脑：http://本机IP:6006（需放行防火墙 6006）
  停止：双击 run\停止.bat
        ★ 拔移动硬盘前务必先停止，否则数据库可能损坏！

------------------------------------------------------------
四、服务与端口
------------------------------------------------------------
  5432  PostgreSQL 数据库（pgvector 向量扩展）
  8001  BGE-M3 本地向量服务（CPU 推理，完全离线）
  8002  py-feat 表情分析网关（离线权重）
  6007  Flask 后端 API
  6006  Next.js 前端页面（用户访问入口）

  AI 聊天走 DeepSeek 线上 API（需联网 + 密钥）；
  向量化与表情分析全部本地离线运行，不上传任何数据。

------------------------------------------------------------
五、常见问题
------------------------------------------------------------
  Q1 换了一台电脑还能直接用吗？
     能。启动脚本会自动重建本机需要的目录联接（junction），
     无需重新初始化。只需该电脑是 64 位 Windows 10/11。

  Q2 启动.bat 里 embed 服务出现 [WARN]？
     向量模型首次加载较慢，脚本最多等 5 分钟。若超时，
     查看 app\logs\embed.log；期间其余功能照常，仅 RAG
     检索降级。

  Q3 数据存在哪里？会留在使用过的电脑上吗？
     全部数据都在本文件夹 data\ 与 app\uploads\ 内，
     不会写入电脑系统盘。拷贝文件夹 = 拷贝全部数据。

  Q4 安全建议
     - 硬盘含学生心理数据与 API 密钥，建议开启 BitLocker。
     - app\.env 中 SECRET_KEY 为默认值，正式使用前建议更换。

  Q5 日志在哪？
     app\logs\pg.log / embed.log / gateway.log / api.log / web.log

------------------------------------------------------------
六、GitHub 开源版本说明
------------------------------------------------------------
本仓库提供项目源代码和 Windows 便携版部署脚本。

便携版启动需要完整的 runtime、models、app、data
目录，仅下载 GitHub 中的脚本无法直接运行。

数据库默认账号密码仅供本地开发和演示使用。
正式部署到公网前，必须更换数据库密码、
应用密钥，并同步修改相关连接配置。

严禁将 .env、真实用户数据、数据库文件和
API Key 上传到公开 GitHub 仓库。
